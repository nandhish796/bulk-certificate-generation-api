# Submission Checklist

- [ ] Install dependencies with `python -m pip install -r requirements.txt`.
- [ ] Run tests with `python -m pytest -v` and confirm all tests pass.
- [ ] Start the API with `python app.py`.
- [ ] Check `GET http://127.0.0.1:5000/health`.
- [ ] Test job creation, job status, and certificate download in Postman.
- [ ] Include screenshots of the successful API responses and a sample PDF if requested.
- [ ] Do not include virtual environments, caches, local databases, or private credentials in the ZIP.
